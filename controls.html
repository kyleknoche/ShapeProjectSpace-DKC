The generic library, on its own.

This page registers Gen 2 and nothing else. No application element is defined, no project module is imported, and every control below is being used exactly as an unrelated project would use it. The monitor on the right records the events the controls emit, live.

A label with a for attribute performs its abstract action by moving focus. Without one it reports handled: false rather than inventing a meaning.

text · htmlFor · variant · muted · required · targetElement() · abstractAction: activate

A disabled or busy button still answers performAction(), reporting handled: false. Callers can tell "nothing happened" from "no such control".

text · variant · size · disabled · busy · command · invoke() · abstractAction: invoke

Typing emits tg-input. Committing emits tg-change and tg-action. The value property and the draft are different things, on purpose.

value · draftValue · label · placeholder · hint · type · maxLength · disabled · readOnly · required · commit() · validate() · abstractAction: commit

The counter appears only when a maximum is set, and turns when the limit is reached.

value · draftValue · rows · maxLength · autoGrow · disabled · readOnly · required · commit() · abstractAction: commit

Clicking and calling toggle() take the same path: the DOM listener turns the gesture into a payload and the abstract action does the rest.

checked · indeterminate · label · description · disabled · required · toggle() · check() · uncheck() · abstractAction: toggle

The group is the control. Options are data, and rows are reconciled by value, so replacing the options keeps the rows whose values survive.

items · value · orientation · disabled · required · selectValue() · getItem() · abstractAction: select

Backed by a native select so typed navigation, popup placement and mobile pickers are the platform's.

items · value · placeholder · disabled · required · selectValue() · selectedItem · abstractAction: select

Arrow keys move, Enter activates, double click activates, Ctrl+click extends a multiple selection. Selection and activation are separate events because they are separate intentions.

items · value · values · selectionMode · orientation · activateOnSelect · selectValue() · toggleValue() · activateValue() · abstractAction: activate

Visible nodes are flattened into one row list and reconciled by id. Expanding a branch inserts rows; it does not rebuild the tree.

nodes · selectedId · expandedIds · expand() · collapse() · expandAll() · selectNode() · revealNode() · abstractAction: activate

A real treegrid: rows are reconciled by node id and cells by column key, so changing the columns keeps the rows and changing the data keeps the columns.

columns · nodes · treeColumnKey · showHeader · expand() · selectNode() · cellValue() · abstractAction: activate

Click a header to sort, double click a row to activate it, Space toggles a selection. Sorting is done on a copy; the rows array handed in is never reordered.

columns · rows · rowKey · selectionMode · sortBy() · getRow() · selectRow() · displayedRows() · abstractAction: activate

A failed load produces a readable message rather than a broken-image glyph, and emits tg-error. The class is ImageView because Image is a global constructor.

src · alt · caption · fit · ratio · lazy · loadState · resolve() · naturalSize() · abstractAction: resolve

Every panel on this page is this control. A panel that is not collapsible answers its abstract action with handled: false.

heading · subheading · collapsible · collapsed · variant · expand() · collapse() · setContent() · appendContent() · abstractAction: toggle

Form imports no other control. A descendant takes part because it exposes isFieldControl, a name, a form value and a validate method, which is why a control from outside this library could join in.

getValues() · setValues() · validate() · reset() · submit() · fields() · setFieldError() · abstractAction: submit

value · max · state · message · indeterminate · dismissible · setProgress() · advance() · report() · snapshot() · abstractAction: acknowledge
